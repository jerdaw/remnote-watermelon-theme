# Surprising Watermelon — RemNote Theme

A light and dark mode theme for [RemNote](https://www.remnote.com/), adapted from the [Bearded Theme "Surprising Watermelon"](https://github.com/BeardedBear/bearded-theme) color palette by BeardedBear.

---

## Preview

**Dark Mode** — Deep teal backgrounds, coral accents, and a warm watermelon-red highlight system.

**Light Mode** — Soft sage greens with matching coral accents, easy on the eyes.

---

## Features

- ✅ Full **light and dark mode** support (single theme file)
- ✅ Custom **heading styles** (H1 accent fill, H2 top border, H3 left rail)
- ✅ **Inline code** styling with monospace chip treatment
- ✅ **Quote chips** — tight, text-hugging, no left rail
- ✅ **Highlight colors** (red, orange, yellow, green, blue, purple) with proper contrast
- ✅ **Cloze** card styling
- ✅ **KaTeX** math rendering support
- ✅ **Scrollbar** theming
- ✅ **Demo Tabs** plugin compatibility
- ✅ **Bold/italic/underline/link** color accents

---

## Installation

### From the Theme Marketplace

Search for **"Watermelon Theme"** in RemNote's Theme Marketplace and click Install.

### Manual Install

1. Download this repository as a ZIP.
2. In RemNote, go to **Settings → Plugins and Themes → Build Tab**.
3. Click **Upload Theme** and upload the ZIP.

## Color Palette Reference

The theme is adapted from the Bearded Theme "Surprising Watermelon" VSCode palette. An unaltered copy of the original VSCode color definitions is preserved in [`reference/bearded-theme-surprising-watermelon.json`](./reference/bearded-theme-surprising-watermelon.json) for reference.

| Background | `#142326` | `#f1f6f4` |
| Foreground | `#c1d9de` | `#263f46` |
| Accent (coral) | `#da6c62` | `#da6c62` |
| Cyan | `#00B3BD` | `#008c98` |
| Green | `#a9dc76` | `#7eaf4f` |
| Purple | `#c47cbf` | `#a45ea0` |
